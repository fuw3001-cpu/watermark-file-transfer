# 拾影 · 安卓本地短视频收藏与文件转换工具

原生 Kotlin / Jetpack Compose 安卓 App。参考 MIT 项目 [parse-video](https://github.com/wujunwei928/parse-video) 和 [media-parser](https://github.com/ucmao/media-parser) 移植抖音、小红书公开内容解析逻辑，文件转换使用 Android 原生图片编解码与 LGPL FFmpegKit。不启动服务器、不调用第三方解析服务、不接广告。

## 当前功能

0.9.9 优化三项本地处理。兼容的 H.264 画面和 AAC 音轨可直接封装到 MP4，转换完成后在页面顶部打开或分享文件。扫描的黑白文档模式保留粗笔画和实心标记。去水印按涂抹区域及周围像素计算，预览后可以切换「原图对比」检查效果。

0.9.8 改进抖音、小红书图集保存。标记为动图的条目会检查多帧内容，主地址失效、内容不完整或只返回封面时会尝试备用地址。GIF、动态 WebP、APNG 按原格式保存。实况图可从视频补封面，保存实况照片或完整 MP4，也可在图集卡片点「实况另存 GIF」输出前 10 秒的无声动画。

0.9.7 在首页用实物缩略图标出三个常用工具。表情包工作台可直接试用猫咪贴纸，内置模板增加至 12 款。可浏览本地推荐、查看全部模板，或点爱心收藏，下次打开仍能找到。保存 PNG 后可直接分享成品或开始下一张。扫描的「管理页面」提供整份文档的缩略图，选中一页，点「移动到…」再选目标页码即可调序。
0.9.6 的扫描页在标题栏导出，可手动裁边时放大查看角点，或把当前滤镜应用到整份文档。校对后的 OCR 文字按页保留在当前编辑会话。表情包新增拍立得、电影胶片、对话气泡、像素掌机、旅行邮票和入场券，共九款内置模板。导入头像后可查看三个本地推荐。推荐综合正脸、抠图轮廓和宽高比，也可以单独用配文生成 PNG。

0.9.5 采用墨绿与暖白配色，首页可直达图片去水印、表情包和扫描。去水印页附有可涂抹的离线示例照片。表情包模板提供缩略图，横屏宽度足够时可并排查看预览与编辑控件。

- 粘贴整段分享文案，或通过其他 App 的「分享 → 拾影」接收文字。
- 识别抖音短链接、视频/图文长链接（`video` / `note` / `slides`）与 `modal_id` 链接。支持图集映射和公开 slidesinfo 后备、Flight 流式 JSON 与 camelCase 字段；已有用户样本通过网页加载后提取、下载两张图片的验证，纯 HTTP 直连仍可能受限。
- 支持小红书整段分享文案、`xhslink.com` / `xhslink.cn` 短链及 `/explore/`、`/discovery/item/` 笔记链接，保留原始 `xsec_token` 等参数。
- 小红书支持公开笔记视频和图集：提取目标笔记的标题、作者与媒体地址；图集支持滑动、大图、逐张/全部保存，同次解析跳过已保存图片。最多 100 张，图片单张 64 MB，实况视频单条 128 MB，下载总计 512 MB，保存到 `Pictures/Shiying`。
- **0.9.3：**抖音读取每张图片的视频地址，小红书读取 `imageList[].stream.h264/h265`，实况图支持播放、单独保存 MP4，以及 JPEG+MP4 的 Android Motion Photo 保存。JPEG 封面像素和 MP4 不重新编码，非 JPEG 封面转为质量 98 的 JPEG；相册能否识别实况取决于厂商兼容性，不保证成为苹果 Live Photo。视频缺失或下载失败会报错并清理本次保存，不静默保存成普通图。
- **0.9.3：**优先保留显式 GIF/动态图地址与 WebP 原链接，避免主动请求 JPG 造成静态化。GIF/动态 WebP 按原字节保存，并使用动画解码器预览；平台若只返回静态图，则无法凭空恢复动画。已明确标记为动图的资源若返回 JPEG 会拒绝保存。
- 小红书按桌面/移动 User-Agent 依次尝试公开页面；失败后可手动使用网页辅助模式。不加载第三方解析 API，不内置用户 Cookie，也不执行解析得到的脚本。
- 在手机端请求平台移动端详情接口或公开分享页，匹配目标作品，提取播放资源和作者、标题、封面；优先使用 H.264 播放地址。
- 0.9.2 抖音直连失败后自动使用临时 WebView 加载公开作品页，每 700 毫秒读取一次页面数据，辅助加载最多 22 秒；正常过程不展示网页、不需要手动提取，成功后直接显示原有图集/视频结果，支持单张和全部保存。可随时取消，结束时销毁网页并清理 Cookie/网页存储。平台明确要求登录或验证时才提供「完成平台验证」入口；小红书仍保留手动网页辅助。
- 视频预览、保存到系统相册的 `Movies/Shiying`，显示下载进度并支持取消。
- Android 10+ 通过 MediaStore 写入自己创建的视频，无需广泛存储权限。失败或取消会删除未完成的相册条目。
- 首页提供「链接收藏」与「本地工具」两个标签。链接页可长按输入框粘贴，或点「从剪贴板粘贴」读取文字，支持清空。跟随系统深色模式。「关于」提供简短介绍，完整版权与许可可点「开源许可」查看。
- 「本地工具 → 文件转换」入口：通过系统文件选择器读取原文件，本地转换后单独保存，不覆盖原文件。
- 「本地工具 → 图片去水印」支持本地静态图、画笔涂抹、撤销、重做及清空、OpenCV 局部修复预览和 PNG 另存。输入最多 6400 万像素，处理最长边 4096、最高 1200 万像素，不放大小图；最多 100 笔、每笔 2000 点，单次选区不超过画面 25%。适合小块水印和简单背景，复杂纹理可能有痕迹；不支持动图逐帧修复。保存成功清空素材/选区并保留结果分享，失败或取消保留输入。
- 转换页仍可进入图片去水印与表情包工作台，返回后继续编辑所选文件。转换完成后可用系统分享面板发送图片、音视频或文档。
- JPG / PNG / WebP 静态图片互转（也可输入 GIF 提取首帧），JPG 和 WebP 可设置质量；JPG 透明区域填白，PNG/WebP 保留透明度。按 EXIF 方向解码，输出不保留原始 EXIF。动态图仅导出第一帧。
- 视频重新编码为 MP4（MPEG-4 Part 2 + AAC），保留第一路视频与可用的第一路音轨；不是简单改扩展名，不保证比原文件小。
- GIF 动图：选择本地视频或 GIF，设置起点（0–3600 秒）、时长（1–10 秒）、帧率（5–15 fps），最长边缩到 480 像素，生成循环、无声 GIF。支持 GIF 转 MP4；不会把只改扩展名当转换。动图保存到 `Pictures/Shiying`，应用内支持动画预览。
- 0.7.0 表情包工作台：选择素材后使用随包 U2NETP 模型本地抠图，选择原创熊猫头、海报框、漫画框或导入自己的图片模板。主体可拖动、双指缩放；最多 5 段文字，每段可编辑 80 字、改颜色、拖到画布内任意位置并缩放字号，也提供方向按钮和缩放按钮。文字叠在图片内，导出 1024×1024 PNG 到 `Pictures/Shiying`，可打开系统分享面板。
- 「本地工具 → 表情包工作台」固定显示预览，提供「头像 / 文字 / 模板」编辑区。替换头像保留文字、位置、缩放、镜像及已有原图模式；支持水平镜像和 15%–800% 缩放滑杆。文字输入获焦时全选，便于直接替换，支持字号滑杆、顶部/中央/底部居中、复制文字层和清空内容；复制沿用颜色与字号，最多仍为 5 段。保存后在预览区查看结果并分享。
- 抠图不调用云端服务；背景复杂、细发丝、细绳等不保证精细保留。可选择保留原图或导入已有透明 PNG。熊猫头模板的主体被限制在脸部窗口内，自定义模板等比放入方形画布；GIF 素材只取首帧。未保存的工程只留在当前应用进程，不提供工程文件、动画字幕或商店发布。
- 「本地工具 → 文档扫描」：CameraX 相机结合 OpenCV 实时检测纸边，识别到纸张即提前对焦，与约 1.2 秒稳定判断并行；拍摄时复用近期对焦请求，未完成时额外等待上限由 1 秒缩至 350 毫秒。支持连扫、手动拍摄及补光；每拍完一页需移开纸张再放入下一页。也可使用系统相机、相册多选及手调四角。支持透视校正、90°旋转、原色/提亮/灰度/黑白，最多 20 页。实际拍摄耗时仍受设备对焦、曝光和 CameraX 拍摄管线影响。
- 扫描页可导出为单个 A4 PDF（按页面方向选择横/竖页，等比居中）或逐页 JPG，也可调用系统分享和打印。PDF 存入 `Downloads/Shiying`，JPG 存入 `Pictures/Shiying`。扫描 PDF 是图片页，不带搜索文字层；可在已有文件转换里继续转 Word。
- 扫描支持当前页简体中文/英文离线 OCR，识别结果可编辑和复制，编辑文字不会改动扫描图片。保留导入原始字节，预览最长边 1600；OCR/导出原片解码上限为长边 6000、1200 万像素，再按纸边和目标尺寸进行三次插值透视校正，避免按输出尺寸预先缩图丢失裁剪区域细节。提亮增强增加有限幅度的细线锐化并限制暗部增益。导出可选标准 2000、高清 3508 及超清 4800（新扫描默认），分别限制 400/1000/1200 万像素，不放大小图。已恢复的草稿保留此前质量选择。
- 文件转换、表情包、文档合并及扫描导出均在保存成功后清空素材、文字或文件列表，保留结果查看/分享入口；失败、取消时仍保留输入。原始相册和外部文件不删除，扫描成功导出后仅清理应用内草稿副本。
- 从音频或视频提取第一路音轨为 192 kbps、44.1 kHz、双声道 MP3；没有音轨时提示错误。
- 图片结果存入 `Pictures/Shiying`，视频存入 `Movies/Shiying`，MP3 存入 `Music/Shiying`。显示转换阶段与可用进度，支持取消，并清理本次临时文件和未发布的结果。
- 文档互转：Word（DOC/DOCX/ODT/RTF）→PDF，Excel（XLS/XLSX/ODS）→PDF/CSV，CSV→XLSX；本地 LibreOfficeKit 在独立进程中处理，Office 引擎目前仅支持 ARM64 手机。
- PDF→DOCX：读取文字层及坐标；扫描页或文字不足的页使用随包提供的简体中文/英文 Tesseract OCR，旋转页也通过渲染后识别。按原页面尺寸和位置重建可编辑文本框，并保留图片、线条等栅格背景。结果存入 `Downloads/Shiying`。
- 「本地工具 → 文档合并与打印」：多选 PDF、Word、Excel，支持上移、下移、移除和命名，按当前列表顺序生成一个 PDF 并保存到 `Downloads/Shiying`。Word/Excel 先在本地转为 PDF，现成 PDF 保留原页面尺寸，不先转成图片。
- 合并完成后打开 Android 系统打印面板，也可打印文件转换产生的单个 PDF。系统面板选择打印机、页码、份数、纸张，双面等能力由打印机和打印服务决定；应用不会自动选择打印机或直接提交出纸。只选部分页码时生成对应页面的打印数据。

## 重要限制

这是开发初版，不是已经验证所有链接或文件可用的成品。抖音支持公开视频及可取得目标详情的图集数据，小红书支持公开笔记视频和图集；快手与广告均未实现。抖音图集分享页有时只返回页面配置而无图片，公开详情接口也可能受限；0.6.0 的用户实链直连测试未通过，0.6.1 已验证该样本的网页辅助解析/图片下载。0.9.2 改为自动加载与提取，不弹出网页；若检测到验证要求，则提示用户打开平台验证页面自行处理。不保证所有作品或网络环境都能恢复，也没有自动通过登录或验证。自动加载的真实手机行为仍待设备验收。小红书私密、删除或需登录/验证且未提供公开详情的笔记可能无法解析；剪掉分享链接的参数也可能导致失败。

小红书图片优先尝试公开媒体的原图/简化处理地址，失效时尝试页面提供的备用资源；可能仍是平台压缩或带水印的版本，不保证原始分辨率或任意笔记都无水印。下载校验 JPEG/PNG/WebP/GIF 文件头，拒绝把登录 HTML 当图片保存。一次图集保存失败或取消会清理本次创建的相册条目；进程被系统结束后的清理不保证。

**扫描限制：**纸张与背景对比不足、反光、模糊或遮挡时，自动边框可能不准确，需手动调整；不提供书页曲面展平、证件专用拼版或手写保证识别。照片最多 6400 万像素、单张原片 128 MB、原片合计 512 MB，高清导出受源分辨率和所选质量上限约束，导出 PDF 最大 256 MB。高质量输出不能恢复原片缺失的细节。拍照仅生成应用内草稿，不会自动把原始拍摄文件写入相册，请及时导出。临时页保存在应用缓存，页面元数据支持系统恢复时续接；成功导出会清空草稿，清缓存或重新开始也可能丢失未导出的内容。「新建扫描」清空前会确认，不删除已导出文件或相册原图。

**合并/打印限制：**一次 1–20 个文件，每个最多 64 MB，输入总计最多 256 MB，合并后最多 500 页、512 MB。单个文件也可生成 PDF 后打印。PDF-only 合并不依赖 ARM64 Office 引擎；混合 Word/Excel 时仍需要 ARM64 手机。原文件不覆盖，暂不支持加密文件；新生成的 PDF 不保证原始数字签名或交互表单的语义仍有效，请保留原件。系统打印需要设备提供打印功能及对应打印服务；是否联网由你选择的系统打印服务决定，本项目不搭建云打印服务器。

**文档限制与真实支持范围：**单个文档最多 64 MB；PDF→Word 最多 20 页，支持简体中文和英文，扫描件应清晰且方向正确。版式优先的 Word 文字以浮动文本框编辑，不是普通可重排段落；表格线和插图主要以背景保存，不生成真正可编辑的表格单元格。复杂公式、多栏、字体替换、背景擦除和 OCR 错字都可能影响结果。不能保证与原 PDF 一致，也不能把编译通过等同于版式保真已验证。

Word/Excel→PDF 使用 LibreOffice 排版，可能因字体或打印区域与 Microsoft Office 不同而变化；不支持密码保护文件。Excel→CSV 只导出当前工作表的值，丢失其他工作表、公式、图片和样式；CSV→Excel 适合 UTF-8 逗号分隔文件，类型推断可能改变前导零、日期等。不要把它当成工作簿无损互转。

Office 引擎和 OCR 模型随 APK 提供，0.3.0 包体约 163 MiB（170 MB）；首次使用会在私有目录解包约 46 MiB 的 Office 资源并复制约 6 MiB 的模型。建议预留至少 500 MB 空间供输入、输出与临时文件使用。文档不上传，不调用云端 OCR。

0.7.0 起默认交付 Android 10+ 的 **ARM64 手机优化包**（arm64-v8a）；默认不再包含 x86_64/ChromeOS 代码。开发者可用 `-PshiyingAbis=arm64-v8a,x86_64` 构建双架构开发包，Office 引擎仍仅 ARM64。文件转换单文件最多 512 MB；图片最多 1600 万像素。转换需要临时复制输入和生成输出，请预留足够存储空间并保持 App 开启；当前不保证后台运行、断点恢复或进程被系统结束后的清理。音视频可用格式取决于 FFmpeg 实际支持的编解码器；损坏、加密或特殊编码的文件可能失败。

平台有时不再在分享页中提供视频详情，或要求验证/登录。本项目会尝试两个平台移动端详情接口，仍未命中则使用分享页；网页辅助也只读取公开页面数据，不能保证恢复。上游另有需要 Cookie 的签名详情后备，本项目尚未移植，也不内置账号凭据。不会以模拟数据冒充解析成功。

实际解析和下载直接连接平台及其媒体 CDN，仍然需要网络。`playwm` → `play` 仅修改已知官方播放接口；不会对下载画面做擦除、修补或转码，因此不保证任何输入都能得到无水印画面。

当前最多保存 512 MB 的 MP4 文件，会检查 MP4 文件头，拒绝将 HTML 验证页保存成视频。下载需要保持 App 进程运行；切换应用后系统可能终止任务，暂不支持后台下载保证、断点续传或恢复任务。

仅用于保存你拥有或已获授权的内容。代码的开源许可不提供视频内容或平台服务的授权。

## 构建

需要 JDK 17、Android SDK Platform 35、Python 3 和网络。Gradle Wrapper 版本为 8.9；首次构建会下载依赖，以及准备脚本中固定版本/校验和的 LibreOffice 资源、中英文 OCR 模型。Tesseract4Android 从限定 group 的 JitPack 仓库解析。手机安装后无需再下载文档引擎或模型。也可以用 Android Studio 打开本目录并配置 SDK。

在根目录创建不提交的 `local.properties`：

```properties
sdk.dir=C:/path/to/Android/Sdk
```

Windows PowerShell：

```powershell
$env:JAVA_HOME='C:/path/to/jdk-17'
$env:SHIYING_PYTHON='C:/path/to/python.exe'
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

macOS / Linux：

```bash
SHIYING_PYTHON=python3 sh gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

调试安装包输出：`app/build/outputs/apk/debug/app-debug.apk`。0.7.0 起建议安装 `:app:assembleRelease` 输出的优化包，开启 R8 和资源裁剪，保留 JNI 名称与回调，仍包含本地音视频、Office、OCR 和抠图模型。当前 release 为方便覆盖旧开发版，使用同一开发签名；正式渠道发布仍需配置自己的签名。

包体基线 157,873,030 字节，0.7.0 优化包约 111 MB，减约 30%（精确结果见验证记录）。这不等于手机设置中的安装占用：ARM64 原生库解压约 226 MiB，其中 Office 库约 180 MiB，首次 Office/OCR 使用还会复制资源。保留完整离线文档能力时，不承诺把用户看到的 436 MB 降到某个具体数值。加密 PDF 和签名验证原本不在支持范围，优化包移除其可选 BouncyCastle 提供方；JPEG-2000 插件也未打包，含此编码图片的 PDF 可能无法处理。

本次实际检查及尚未覆盖的设备项目见 [验证记录](docs/verification.md)。

## 代码结构

- `parser/ShareLinks.kt`：分享文案和域名校验。
- `parser/DouyinResolver.kt`：直接请求平台与有限次数的跳转处理。
- `parser/DouyinDocument.kt`：公开页面数据映射，单元测试覆盖分享文案、错误作品匹配、图集拒绝和官方播放地址转换。
- `storage/VideoSaver.kt`：流式下载、文件校验和 MediaStore 保存。
- `parser/XiaohongshuResolver.kt` / `XiaohongshuDocument.kt`：小红书限定域名跳转、公开状态解析、笔记 ID 匹配与视频/图集映射。
- `storage/ImageSaver.kt`：两个平台图集下载、备用资源、格式识别与失败回滚。
- `ui/`：首页、平台网页辅助、视频和图集预览、转换和模板表情包工作台。
- `meme/`：离线主体抠图、图层/拖动坐标、内置模板绘制和 PNG 合成。
- `scan/`：纸边检测、四角几何、透视和滤镜、多页草稿、PDF/JPG 导出；`documents/LocalOcr.kt` 与 PDF 转 Word 共用离线模型。
- `conversion/`：文件读取、图片编解码、FFmpeg/FFprobe 异步转换、参数数组和 MediaStore 输出。
- `documents/`：LibreOffice 隔离进程、PDF 坐标提取、离线 OCR 与版式 DOCX 写入。
- `documents/DocumentMerger.kt` / `PdfMergeCore.kt`：文件准备、混合文档 PDF 归一化、顺序合并与打印页码处理；`PdfPrinter.kt` 对接系统打印。
- `tools/prepare_documents.py`：固定下载与 SHA-256 验证，等长重定位 LibreOffice 引擎路径，准备随 APK 分发的资源。
- `third_party/`：两个上游项目的参考快照及 MIT 许可证；完整来源和版本见 [第三方声明](THIRD_PARTY_NOTICES.md)。

可选真实网络验收（默认单元测试不会请求平台）：设置 `SHIYING_LIVE_LINK` 为你自己的或已获授权的分享链接，再运行 `:app:testDebugUnitTest --tests '*LivePlatformTest' --rerun-tasks`。可选设置 `SHIYING_LIVE_VIDEO_PATH` 为本机输出路径，验证完整下载；不设置时仅验证媒体响应的 MP4 文件头。不要把包含用户参数的分享长链接或临时 CDN 地址提交到仓库。

可选离线音视频命令验收：设置 `SHIYING_FFMPEG` 为本机 FFmpeg 路径（同目录应有 ffprobe），运行 `:app:testDebugUnitTest --tests '*DesktopConversionTest' --rerun-tasks`。该测试生成合成 AVI，使用生产转换参数生成 MP4/MP3 并完整解码；它不执行安卓 JNI 库。

安卓设备验收：连接 64 位 Android 10+ 设备后运行 `:app:connectedDebugAndroidTest`。设备测试覆盖 JPG/PNG/WebP 图片尺寸、透明度、原文件保留，以及实际 FFmpegKit 转 MP4/MP3 和 MediaStore 发布；设备测试会创建并清理自己的合成文件，不访问网络。

文档设备测试额外覆盖中英文扫描 PDF→可编辑 DOCX，以及 ARM64 的 Word→PDF→Word 基本往返。当前开发环境没有连接安卓设备，因此这些测试仅编译，不能声称 OCR 准确率、Office 引擎运行和版式保真已通过验收。字体、图像、表格、分页和实际扫描样本仍需逐页对照检查。

FFmpegKit 的 LGPL 许可、对应源码/构建脚本、库替换说明与二进制版本记录见 [third_party/ffmpegkit/README.md](third_party/ffmpegkit/README.md)。这不是免除开源许可义务的商业授权。

## 真机验收

自动测试不代表平台接口或安卓设备可用性验证。安装后应使用一条你拥有或已获授权的公开视频逐项检查：

1. 分别粘贴抖音、小红书分享文案，核对标题和作者是否为目标作品；小红书保留完整参数。
2. 播放预览，检查画面内容及水印情况。
3. 保存后从系统相册播放，确认是完整视频。
4. 下载途中取消、断网和重试，检查没有留下损坏文件。
5. 从抖音分享文字到拾影，检查接收内容。
6. 检查深色模式、大字体、横屏、网页验证与错误提示。
7. 在「文件转换」分别选择 JPG/PNG/WebP、AVI/MOV/MKV 等本地样本，转换后打开结果，核对方向、透明度、画面和声音；仅实际验证过的格式才可视为可用。
8. 用无音轨视频测试提取 MP3 的错误提示；转换中取消并检查原文件仍在、未留下半成品；从系统文件管理器确认结果所在目录。
9. 在 ARM64 手机选择包含中英文、表格、图片和分页的 Word/Excel，转换 PDF 后逐页检查；分别用文字型 PDF 和扫描 PDF 转 Word，核对可编辑文本框、页数、字形、位置、OCR 错字和插图。检查 CSV 导出工作表和编码。
10. 用小红书公开单视频与多图笔记测试预览和完整保存；检查文件类型、图片数量、取消/失效地址回滚、网页验证后的提取，以及 LivePhoto 仅静态图片的行为。
11. 多选 PDF/Word/Excel，调整顺序并合并，检查页数、横竖页面尺寸、文字、图形与表格。进入系统打印，先选择“另存为 PDF”检查指定页码，再在实际打印机上验证纸张、份数、双面和取消行为。

小红书可选真实网络验收：设置 `SHIYING_LIVE_XHS_LINK` 为你自己的或已获授权的公开分享链接，运行 `:app:testDebugUnitTest --tests '*XiaohongshuLiveTest' --rerun-tasks`。该测试验证目标笔记和媒体文件头，不代替真机预览、完整下载和相册保存；默认未设置环境变量时跳过。测试链接及临时 CDN 地址不要提交到仓库。

可选设置 `SHIYING_XHS_OUTPUT` 为本机临时目录以完整下载该笔记返回的媒体，逐个检查长度及文件头。请放在忽略提交的位置，避免把用户笔记与临时下载地址纳入源码。

PDF 合并 JVM 测试使用真实 PdfBox-Android 引擎和有效 PDF 文件，仅在测试源码中替代 Android 的日志输出；不 mock PDF 解析或合并。设置 `SHIYING_PDF_QA_DIR` 可保留合并/选页 PDF 样本，用 Poppler 等查看页面与文字。该测试不代替 Android 打印面板或实际打印机验收。

抖音图集可选实链验收：设置 `SHIYING_LIVE_DOUYIN_GALLERY` 为已授权公开分享链接，运行 `:app:testDebugUnitTest --tests '*DouyinGalleryLiveTest' --rerun-tasks`。设置 `SHIYING_DOUYIN_GALLERY_OUTPUT` 可完整下载图集到忽略提交的目录；不设置时只验证第一张的文件头。未返回目标详情时测试会失败，不记为通过或跳过。

GIF 命令验证沿用 `SHIYING_FFMPEG` 和 `DesktopConversionTest`，可选 `SHIYING_GIF_QA_DIR` 保留合成样本。它验证桌面 FFmpeg 的真实生成、帧数、尺寸、时长与 GIF→MP4 解码，不代表安卓 JNI 已执行。设备测试已加入 GIF 原生生成/动画解码、文字在画布内移动、透明主体模板合成和 PNG 像素保存验证，需连接手机运行。

0.6.1 网页辅助验收：在隔离浏览器中打开已授权的作品页，用 App 的提取脚本导出页面数据。设置 `SHIYING_DOUYIN_BROWSER_HTML` 为导出的 HTML，`SHIYING_DOUYIN_BROWSER_URL` 为该作品的抖音标准地址，可运行 `DouyinGalleryLiveTest.authorizedBrowserPageReturnsRealImages`。可继续用 `SHIYING_DOUYIN_GALLERY_OUTPUT` 完整下载图片。它只验证网页辅助数据解析/下载，不将其算作纯 HTTP 直连成功；不要提交真实网页、签名参数或用户图片。

扫描输出验收可设置 `SHIYING_SCAN_QA_DIR` 运行 `ScanPdfTest`，保留合成 JPG 形成的 PDF；用独立 PDF 阅读器检查两页方向、页序和画面。JVM 测试不执行 Android 相机、透视 Matrix 或真实 OCR；新增 `ScanDeviceTest` 覆盖透视四角颜色/旋转和文件转换成功清空、失败保留选择，需连接手机运行。

0.9.0 新增 `AutoScanTest` 验证稳定触发、防重复、模糊/移动重置和高清尺寸/滤镜；`WorkflowResetDeviceTest` 验证表情包与合并清空、失败保留、扫描原片字节及高清导出。设备测试需连接 ARM64 手机执行；自动相机纸边对齐、对焦、连扫和画质仍需真实镜头验收。

交付用安装包复制到 `dist/shiying-0.9.9-arm64.apk`（忽略提交），避免后续 Gradle 重建时清理旧的下载文件。

实况图片验证可设置 `SHIYING_MOTION_QA_DIR` 后运行 `MotionPhotoTest`，保留 JPEG+MP4 样本；用独立图片阅读器检查封面，用 `GCamera:MicroVideoOffset` 提取尾部视频后完整解码。此检查不等于厂商相册兼容性验收。`ImageRepairDeviceTest` 覆盖局部水印修复、原图/选区外像素、选区面积限制和取消，需要手机执行。
